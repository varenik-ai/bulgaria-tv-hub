# Кнопка «Поблагодарить» (⭐ Stars) для другого канала

Результат: кнопка под закреплённым постом канала открывает мини-апп сразу с окном выбора ⭐ 25 / 50 / 100 / 250. Новый пост не отправляется, подписчики уведомление не получают.
Эталон реализации: репозиторий `bulgaria-tv-hub` (`index.html`, `bulgaria-bot-worker.js`).

## Что нужно
- Мини-апп на GitHub Pages и бот на Cloudflare Worker (как у Bulgaria TV).
- Бот владеет каналом (администратор с правом «Редактировать сообщения»).
- Секреты бота-воркера: `TOKEN`, `ADMIN_ID` (твой Telegram ID), `SETUP_KEY`.

## Шаг 1. Мини-апп (`index.html`)
1. Скопируй из Bulgaria три куска:
   - стили `.thank-btn` и `#donate-modal`;
   - разметку `#donate-modal` и кнопки `#thank-btn-hub`, `#thank-btn-player`;
   - блок JS «Благодарность через Telegram Stars»: `BOT_API`, `openDonate`, `payStars`.
2. В `BOT_API` укажи адрес воркера **своего** бота (`https://<имя-бота-воркера>.workers.dev`).
3. Добавь в словари языков `T[lang]` ключ `thank` (текст кнопки) для всех языков.
4. **Обязательно** — чтение параметра запуска (Telegram кладёт в адрес `#tgWebAppData=...`, поэтому старый вариант `location.hash` не работает):
   ```js
   const hp = new URLSearchParams((location.hash || '').replace('#', ''));
   const hashId = (location.hash || '').indexOf('=') < 0 ? (location.hash || '').replace('#', '') : '';
   const raw = tg?.initDataUnsafe?.start_param || hp.get('tgWebAppStartParam') || hashId || '';
   if (raw === 'donate') openDonate();
   ```
5. Закоммить и запушить в `main` (GitHub Pages обновится за 1–2 минуты).

## Шаг 2. Бот-воркер
Скопируй из `bulgaria-bot-worker.js`:
- маршрут `/invoice?amount=N` (создаёт счёт `createInvoiceLink`, валюта `XTR`, суммы из `DONATE_AMOUNTS`);
- обработку `pre_checkout_query` (ответ `ok: true` обязателен в течение 10 секунд, иначе платёж не пройдёт);
- обработку `successful_payment` и словарь `thanks` («Спасибо» пользователю);
- команду `/fixpost` (см. шаг 4).
Секреты: `npx wrangler secret put TOKEN`, затем `ADMIN_ID`, `SETUP_KEY`. Деплой: `npx wrangler deploy`.

## Шаг 3. Адрес приложения в @BotFather
Бот открывает мини-апп по адресу, который хранится у Telegram, а не в коде.
1. @BotFather → `/myapps` → выбери бота → выбери приложение.
2. **Edit Web App URL** → `https://<аккаунт>.github.io/<репозиторий>/`.
3. Закрой мини-апп полностью (смахни из недавних) и открой снова.
Проверка: внизу списка каналов виден номер версии и кнопка «⭐ Поблагодарить».

## Шаг 4. Кнопка под постом без нового поста
Кнопка в посте — обычная ссылка на приложение с параметром `donate`:
```
https://t.me/<бот>/<имя_приложения>?startapp=donate
```
- **Если пост ещё не отправлен:** в `/post` поставь эту ссылку в `inline_keyboard` как `url` второй кнопкой.
- **Если пост уже закреплён:** отправь боту команду `/fixpost` (только у админа). Бот возьмёт закреплённый пост канала и заменит кнопки на месте (`editMessageReplyMarkup`). Подписчики ничего не получают, текст поста не меняется. Если кнопки уже верные, Telegram ответит «message is not modified», это нормально.
- Правка работает только для постов, которые отправил сам бот.

## Что заменить под свой канал
| Что | Где |
|---|---|
| `CHANNEL` (`@имя_канала`) | бот-воркер |
| `APP_URL` (`https://t.me/<бот>/<приложение>`) | бот-воркер |
| `WEB_URL` (адрес Pages) | бот-воркер |
| `BOT_API` (адрес воркера) | `index.html` |
| тексты `thanks`, подпись кнопок | бот-воркер, `index.html` |

## Типичные ошибки
- Открывается мини-апп, но без окна оплаты: в @BotFather записан старый адрес (шаг 3) или не добавлено чтение `tgWebAppStartParam` (шаг 1, пункт 4).
- «Не удалось создать счёт»: нет секрета `TOKEN` у воркера или в `BOT_API` указан чужой воркер.
- Платёж не проходит: нет обработки `pre_checkout_query`.
- Кнопка не меняется после `/fixpost`: пост отправлен не этим ботом или в канале несколько закреплённых сообщений, а закреплён нужный не последним.
